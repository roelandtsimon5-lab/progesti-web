# Tutoriel Progesti : créer et envoyer un devis

Un devis qui traîne dans un Word, c’est un devis qui ne part jamais. Le client rappelle, vous rouvrez le mauvais fichier, le tarif a changé, et la signature arrive trop tard.

Ce tutoriel montre le parcours réel dans Progesti : liste Devis → nouveau devis → lignes / totaux → aperçu PDF → envoi. Captures prises sur la démo produit (données fictives Pro Nettoyage Services).

Sur le terrain, le devis sert deux choses : caler le prix avec le client, puis enclencher la mission sans retaper les infos dans le planning.

## 1. Ouvrir la liste Devis

Dans le menu, section **VENTES** → **Devis**.

Vous voyez les devis existants (référence, client, statut, total, nature), le filtre **Tous les devis**, la recherche, et le bouton vert **+ Créer un devis**.

![Liste des devis dans Progesti — filtre Tous les devis, compteur et bouton Créer un devis](/tutoriels/tutoriel-progesti-devis-envoyer/01-devis-liste.png)

Les statuts utiles au quotidien :

- **Brouillon** — encore chez vous
- **Envoyé** — le client l’a reçu (ou le lien de signature est parti)
- **Signé** / **Refusé** — décision côté client

**Terrain :** avant d’en créer un nouveau, cherchez le client. Un second devis « presque pareil » pour le même site finit souvent en double facturation ou en discussion tarifaire confuse.

## 2. Créer un nouveau devis

Cliquez **+ Créer un devis** (ou ouvrez `/devis/nouveau`).

Le formulaire **DEVIS > Nouveau** demande le minimum pour démarrer :

1. **Client** (liste déroulante)
2. **Type** — ponctuelle (1 intervention) ou récurrente
3. **Durée d’un passage** (minutes) — durée du créneau terrain ; le volume hebdo se gère ensuite sur les lignes produit
4. **Date de début** et **heure**

Puis, dans **Lignes du devis**, ajoutez un article via **+ Ajouter un article** (ex. ENTBUREAU — Entretien bureaux horaire).

![Formulaire Nouveau devis : client, type ponctuelle, durée, date, première ligne produit](/tutoriels/tutoriel-progesti-devis-envoyer/03-devis-nouveau.png)

Enregistrez (**Enregistrer** ou **Enregistrer et retour**) dès que le client et au moins une ligne sont cohérents. Mieux vaut un brouillon propre qu’un devis « presque fini » oublié dans un onglet.

**Scénario bureaux :** un open space + un siège = souvent **un** client, plusieurs lieux de passage sur les lignes. Ne créez pas deux devis séparés si c’est le même contrat commercial.

**Scénario syndic / parties communes :** précisez le lieu (hall, cages, locaux poubelles) dès la ligne — ça évite le « c’était pour quelle résidence ? » le jour de la signature.

## 3. Renseigner les lignes et les totaux

Sur la ligne, vous choisissez le **produit**, les **heures** (ou la quantité), le **lieu de passage** si le client a plusieurs sites, le **libellé**, le **tarif HT / TTC** et la **TVA**.

Les totaux se recalculent sous la carte : Total HT, TVA, Total TTC. Une section **Rentabilité** peut s’ouvrir si vous voulez vérifier la marge avant d’envoyer.

![Ligne de devis : produit ENTBUREAU, lieux Salle/Terrasse, tarifs HT/TTC, TVA 10 %, totaux](/tutoriels/tutoriel-progesti-devis-envoyer/04-devis-lignes.png)

**Checklist ligne utile :**

- Bon produit (horaire vs forfait)
- Bon lieu coché (pas le site d’à côté)
- TVA adaptée au type de prestation
- Libellé lisible pour le client (pas seulement un code interne)

## 4. Relire la fiche devis

Une fois enregistré, ouvrez la fiche. Vous voyez le titre, la référence, le statut, le client, les totaux, la nature, le mode / rythme de facturation, et les articles.

Sur un devis déjà avancé, le bandeau d’étapes rappelle le fil : **Devis → Signé → Mission → Planifié**.

![Fiche devis détaillée : client, totaux HT/TVA/TTC, articles, parcours Signé / Mission](/tutoriels/tutoriel-progesti-devis-envoyer/02-devis-detail.png)

Vérifiez surtout :

1. Le **bon client** (raison sociale facturable)
2. Le **bon total TTC** (celui que vous allez défendre au téléphone)
3. Que les **articles** correspondent à ce qui a été dit en visite

## 5. Aperçu PDF avant envoi

Depuis la fiche, ouvrez l’aperçu / impression. Le PDF client affiche l’émetteur, le destinataire, les adresses d’intervention, le mode d’intervention, le rythme de facturation, et le tableau des lignes (désignation, qté, PU TTC, TVA, montant).

![Aperçu PDF du devis : en-tête, client, tableau Entretien bureaux, montants TTC](/tutoriels/tutoriel-progesti-devis-envoyer/06-devis-pdf-apercu.png)

**Terrain :** envoyez seulement après cette relecture. Un PDF avec la mauvaise adresse d’intervention, c’est un devis « signé » qui planifie au mauvais endroit.

## 6. Envoyer le devis au client

Sur la fiche (ou depuis la liste selon le statut), ouvrez l’action d’**envoi email**. La fenêtre **Nouveau message** propose :

- **À** — email du contact
- **Objet** — prérempli (ex. « Votre devis Progesti – … »)
- **Message** — corps libre
- **Aperçu** à droite
- **Envoyer**, ou **Outlook (.eml)** si vous préférez partir depuis votre boîte

![Fenêtre Nouveau message pour envoyer le devis : destinataire, objet, aperçu, boutons Outlook et Envoyer](/tutoriels/tutoriel-progesti-devis-envoyer/05-devis-envoyer.png)

**Astuce gérant :** si l’envoi intégré bloque (réseau, boîte non branchée, mode démo), exportez le **.eml** et partez depuis Outlook / votre messagerie habituelle. L’important, c’est que le client reçoive le bon PDF avec la bonne référence.

Après envoi réussi, le statut passe typiquement à **Envoyé**. Ensuite : signature en ligne si vous l’utilisez, ou passage manuel en **Signé**, puis démarrage de mission / planning.

Pour le détail produit côté site marketing, voir la page [fonctionnalités devis](/fonctionnalites/devis).

## Pièges fréquents

- **Devis sans client clair** → impossible à relancer proprement
- **Ligne sans lieu** sur un multi-sites → l’agent (ou le client) se trompe de porte
- **Envoyer sans PDF relu** → erreur de tarif ou d’adresse dans la nature
- **Deux devis brouillons pour le même besoin** → le client signe la mauvaise version
- **Oublier de basculer Signé → Mission** → le commercial est OK, le planning reste vide
