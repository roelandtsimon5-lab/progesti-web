# Tutoriel Progesti : photos preuve de passage

Le syndic envoie un mail à 10h04 : « personne n’est passé, le hall est sale ». Votre agent jure qu’il a tout fait. Sans photo horodatée liée au passage, vous arbitrez au feeling — et vous perdez du temps.

Ce tutoriel montre le parcours côté gérant dans Progesti : liste **Télégestion** → fiche **pointage** → panneau **Fichier** (Avant / Après) → **intervention** liée. Captures prises sur la démo produit (données fictives Pro Nettoyage Services).

Objectif terrain : en moins d’une minute, ouvrir la preuve photo du passage contesté — pas chercher dans WhatsApp.

## 1. Ouvrir la télégestion (liste des pointages)

Menu **TÉLÉGESTION** → **Télégestion**.

Vous voyez la liste : code agent, nom, client / site, origine (**Application mobile**), événement (**Arrivée** ou **Départ**), heure. En démo : une centaine de pointages, barre de recherche, bouton vert **+ Créer**.

![Liste Télégestion Progesti : pointages mobile Arrivée/Départ, clients, recherche](/tutoriels/tutoriel-progesti-photos-preuve-passage/01-telegestion-liste-pointages.png)

**Terrain :** filtrez d’abord le client qui crie (ou le nom de l’agent). La photo ne vit pas seule : elle est accrochée au pointage, lui-même accroché au passage.

C’est le même socle que la page [pointage & télégestion](/fonctionnalites/pointage) : preuve terrain avant litige.

## 2. Ouvrir un pointage qui a des photos

Cliquez une ligne **Départ** (souvent la fin de présence, là où l’agent joint les clichés).

Exemple démo : **Petit, Camille** — **Garage Auto Service Labège** — **02/07/2026 14:20:00** — origine Application mobile — statut **Télégestion réussie**. L’intervention liée apparaît (créneau 11:15, durée 03:00).

À droite : panneau **Fichier (2)** — ce n’est plus « Aucun élément ». Deux preuves sont listées.

![Fiche pointage : Général + panneau Fichier (2) avec preuves Avant et Après](/tutoriels/tutoriel-progesti-photos-preuve-passage/02-pointage-detail-fichier-photos.png)

**Scénario syndic :** vous n’envoyez pas toute la liste. Vous ouvrez *ce* départ, vous montrez Avant / Après, vous clôturez.

## 3. Lire Avant / Après dans Fichier

Dans **Fichier (2)** :

- **Avant** — horodatage (ex. 02/07/2026 09:30) — bouton **Agrandir**
- **Après** — horodatage (ex. 02/07/2026 09:45) — **Agrandir**

C’est la preuve de passage « avant / après » : état du lieu en arrivant, état en partant. Pas un album Instagram — deux clichés métier liés au badge.

![Panneau Fichier développé : Avant et Après avec horodatage et Agrandir](/tutoriels/tutoriel-progesti-photos-preuve-passage/03-pointage-fichier-avant-apres.png)

**Terrain :** Avant seul = vous savez l’état d’arrivée. Après seul = fin de chantier. Les deux = vous répondez au « hall sale » avec la chronologie, pas avec un SMS d’excuse.

## 4. Croiser avec l’arrivée du même passage

Sur le même site / même intervention, ouvrez aussi l’**Arrivée** correspondante.

Même agent, même client, événement **Arrivée**, heure cohérente avec le créneau. Les photos sont souvent côté départ ; l’arrivée prouve le début de présence (heure + GPS).

![Fiche pointage Arrivée du même passage : Général, intervention liée](/tutoriels/tutoriel-progesti-photos-preuve-passage/04-pointage-arrivee-meme-passage.png)

**Règle gérant :** arrivée + départ + Fichier Avant/Après = dossier complet. Une photo WhatsApp hors app = hors preuve Progesti.

## 5. Autre site : même schéma Fichier

Autre exemple démo : **Garcia, Inès** — cabinet avocats — départ mobile — **Fichier (2)** à nouveau.

Le geste est toujours le même, quel que soit le client. Vous n’apprenez pas un écran par vertical : bureaux, crèche ou garage, c’est Télégestion → pointage → Fichier.

![Autre pointage avec panneau Fichier (2) Avant/Après](/tutoriels/tutoriel-progesti-photos-preuve-passage/05-autre-pointage-avec-photos.png)

## 6. Relier au passage (intervention validée)

Depuis la fiche pointage, ouvrez l’**Intervention** liée (ou **Planning** → **Passages**).

Sur le passage : statut **Validée**, client, créneau, intervenant. La télégestion et les photos nourrissent ce passage — puis la facture du réalisé. Sans ce lien, vous avez des clichés orphelins et une facturation Excel.

![Fiche intervention Validée : Garage Auto Service Labège, créneau, agent](/tutoriels/tutoriel-progesti-photos-preuve-passage/06-intervention-photos-preuve.png)

Plus bas / à côté : bloc **Pointage** (exécution début / fin, statut COMPLETED). C’est le pont heure ↔ photo ↔ facturable.

![Bloc Pointage sur l’intervention : exécution liée au passage](/tutoriels/tutoriel-progesti-photos-preuve-passage/07-intervention-bloc-pointage.png)

## 7. Retrouver vite un agent (filtre)

Retour **Télégestion**. Tapez le nom de l’agent dans **Rechercher…** (ex. Petit).

La liste se réduit : vous ouvrez le bon départ sans scroller toute la flotte. Utile le jour où trois clients écrivent en même temps.

![Liste Télégestion filtrée sur l’agent Petit](/tutoriels/tutoriel-progesti-photos-preuve-passage/08-telegestion-filtre-agent.png)

## Pièges fréquents

- **Exiger la photo sans pointage mobile** → l’agent ne badgé pas ; Fichier reste vide
- **Regarder seulement l’arrivée** → les clichés Avant/Après sont souvent sur le départ
- **Photo uniquement sur WhatsApp** → hors dossier Progesti, hors facture du réalisé
- **Fichier à « Aucun élément »** → pas de preuve image sur *ce* pointage ; la preuve reste heure + GPS + passage lié (voir aussi le tutoriel pointage mobile)
- **Oublier le lien intervention** → vous montrez une photo, le client conteste le *jour* ou le *site*
- **Tout traiter en saisie manuelle** → la preuve s’érode ; gardez le manuel pour l’exception
