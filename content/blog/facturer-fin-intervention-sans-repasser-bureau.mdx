# Facturer en fin d'intervention sans repasser par le bureau

Vendredi 18h40. L'agent vient de finir le grand ménage après travaux. Le contact client est encore sur place. Vous savez déjà ce qui va se passer si vous « notez pour lundi » : le bon disparaît, le devis flou revient, et vous facturez trois semaines plus tard en espérant que personne ne conteste.

La question que posent beaucoup de gérants est simple : **comment facturer immédiatement en fin d'intervention, sans repasser par le bureau ?** Pas pour faire joli. Pour encaisser plus tôt, et pour facturer ce qui a vraiment été fait.

Voici un process terrain. Pas une usine à documents.

## Ce que « immédiatement » veut dire (et ce que ça ne veut pas)

Facturer tout de suite, ce n'est pas improviser un montant sur un coin de table. C'est **fermer la boucle le jour J** :

1. le passage est validé (qui, quoi, où, quand) ;
2. les lignes à facturer sont figées (forfait, heures, suppléments) ;
3. la facture (ou le brouillon prêt à envoyer) part **avant** que le contexte soit oublié.

Ce n'est pas non plus « facturer sans accord ». Si le prix n'était pas cadré, vous ne gagnez rien à envoyer une surprise à 19h. Vous gagnez à **ne plus dépendre du dimanche soir au bureau** pour reconstruire la semaine.

## Pourquoi le retour bureau tue la facture

Le schéma classique dans une TPE de propreté :

- l'agent envoie une photo WhatsApp « c'est fait » ;
- le gérant promet de « faire la facture demain » ;
- demain = trois urgences + un remplacement ;
- fin de mois = Excel, bons papier, mémoire approximative.

Résultat : oubli de demi-journées, suppléments jamais facturés, litiges « on n'avait pas dit ça ». Le problème n'est pas le courage. C'est le **délai entre le terrain et la facture**.

Plus ce délai est long, plus vous facturez du souvenir. Plus il est court, plus vous facturez du réalisé.

## Les 4 conditions avant de pouvoir facturer sur le terrain

Sans ça, « facturer sans bureau » reste un slogan.

### 1. Un prix déjà cadré

Forfait FDC signé, avenant écrit, grille hors-contrat, ou devis accepté. Pas de « on verra ». Si le montant n'est pas clair à l'arrivée sur site, votre priorité n'est pas la facture : c'est l'accord (même SMS daté).

### 2. Une preuve de passage le jour J

Heure d'arrivée / départ, zone faite, photos avant-après si le client est tatillon (syndic, réception de travaux). Sans preuve, une facture rapide devient une facture contestable.

### 3. Un responsable qui valide les lignes

Soit vous (gérant) depuis le téléphone, soit un responsable terrain avec un droit clair. L'agent signale ; quelqu'un **valide** ce qui part en facture. Sinon vous héritez d'erreurs à corriger en crédit.

### 4. Un outil où le passage devient une ligne

WhatsApp + Excel, ça ne « devient » jamais une facture tout seul. Il vous faut un endroit où le passage validé génère (ou prépare) la facture — pas une re-saisie le dimanche. C'est exactement le rôle d'une [facturation branchée sur le réalisé](/logiciel-facturation-proprete) : moins de reconstruction, plus d'envoi.

## Playbook jour J : de la fin de chantier à l'envoi

Scénario type : remise en état bureaux, ou prestation ponctuelle après événement. Adapté aussi à un entretien quand vous facturez au réel (heures / passages), pas seulement au forfait mensuel.

**T−1 (avant l'intervention)**  
Relisez le devis ou le bon de commande. Une ligne = une chose mesurable (zone, forfait, heures prévues). Notez qui valide côté client.

**H0 — fin d'intervention**  
1. Agent (ou vous) clôture le passage : sites, durée, tâches faites.  
2. Preuves jointes si besoin (photos, commentaire « sols + vitres R+2 »).  
3. Client sur place : faites valider oralement **et** gardez une trace (signature, mail, SMS « OK reçu »).

**H0 + 15 min — figer les lignes**  
Depuis le téléphone ou la tablette :

- reprenez le devis / le forfait ;  
- ajoutez les suppléments **déjà validés** (rien d'autre) ;  
- vérifiez TVA, raison sociale, adresse de facturation (souvent différente du site).

**H0 + 30 min — émettre ou programmer l'envoi**  
Deux niveaux acceptables :

- **Idéal :** PDF envoyé le jour même.  
- **Acceptable :** brouillon verrouillé + envoi automatique le lendemain matin 8h (si le client déteste les mails à 19h).  

Ce qui n'est **pas** acceptable : « je le ferai quand je serai au bureau lundi » sans brouillon figé. Lundi, le contexte a disparu.

## Cas bureaux vs fin de chantier vs mensuel

**Ponctuel / FDC**  
C'est là que « sans repasser par le bureau » paie le plus. Une facture le jour de la réception évite le « on n'est pas d'accord sur le périmètre » trois semaines plus tard. Joignez les preuves dans le même fil.

**Entretien mensuel forfaitaire**  
Vous ne refacturez pas chaque passage. En revanche, les **hors-contrat du mois** doivent partir sous 48 h, pas dans la facture du 5 du mois suivant mélangée au forfait. Sinon le client ne sait plus ce qu'il paie.

**Heures / régie**  
Validez les heures le jour J avec le client ou le responsable de site. Facturez dès que le lot de la semaine est clos — pas après avoir « recalculé » sur un tableur douteux.

## Les 5 erreurs qui forcent le retour bureau

1. **Prix flou à l'arrivée** — vous devez rappeler pour chiffrer → vous avez perdu l'immédiat.  
2. **Preuve absente** — vous attendez une photo « qu'on vous enverra » → elle n'arrive pas.  
3. **Trop de validateurs** — quatre personnes doivent « regarder » la facture → elle dort.  
4. **Resaisie manuelle** — chaque copie Excel = une nuit au bureau.  
5. **Mélanger forfait et suppléments** sur une seule ligne opaque — litige garanti, correction au calme… au bureau.

## Checklist pocket (à coller dans le dossier client)

- [ ] Devis / forfait / avenant OK avant le jour J  
- [ ] Passage clôturé (heure, zone, agent)  
- [ ] Preuves si le client est exigeant  
- [ ] Lignes facture = réalisé + suppléments validés seulement  
- [ ] Envoi PDF le jour J **ou** brouillon verrouillé + envoi J+1 matin  
- [ ] Trace de l'accord client rangée avec la facture

Si une case manque, ne forcez pas « l'immédiat ». Corrigez la case. Puis facturez.

## Lien avec le planning (parce que la facture ne vit pas seule)

Une facture propre part d'un passage qui existait vraiment dans le [planning nettoyage](/logiciel-planning-nettoyage) : site, créneau, agent. Si le planning est un fil WhatsApp, vous reconstruirez toujours au bureau. Si le passage est planifié puis validé, la facture n'est plus une enquête — c'est une étape.

## En résumé

1. Cadrez le prix **avant** le jour J.  
2. Clôturez le passage avec preuves le jour J.  
3. Figez les lignes dans l'heure qui suit.  
4. Envoyez (ou verrouillez l'envoi) sans attendre le bureau.  
5. Séparez forfait mensuel et suppléments.

Facturer sans repasser par le bureau, ce n'est pas magique. C'est refuser de reconstruire la semaine de mémoire. Le client a encore le chantier en tête ; vous aussi. Profitez-en.
