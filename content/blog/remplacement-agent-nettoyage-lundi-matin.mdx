# Remplacement d'agent nettoyage le lundi matin : le playbook terrain

Lundi, 6h30. Un SMS : « Je suis malade, je ne peux pas venir. » Trois sites bureaux à 7h, un hall de syndic à 8h. Le client ne veut pas d'excuse. Il veut un local propre.

Ce scénario, tout gérant de propreté le connaît. Ce qui change, c'est la façon de réagir. WhatsApp en rafale, appels croisés, planning Excel ouvert sur le téléphone — ça tient une fois. Pas toutes les semaines.

Voici un playbook concret : détecter le trou, réaffecter un backup, prévenir le client, tracer le passage. Applicable aux bureaux multi-sites comme aux parties communes de syndic.

## Détecter l'absence avant que le site soit orphelin

La première heure compte. Si vous apprenez l'absence à 9h alors que le site a été sauté, vous êtes déjà en mode réclamation.

**Règle simple :** toute absence signalée doit arriver dans un seul canal que vous (ou le responsable planning) consultez en premier le matin. Pas trois groupes WhatsApp + un SMS perso.

Checklist de détection dès l'alerte :

1. **Quel(s) site(s) sont touchés aujourd'hui ?** Horaires, durée, type de prestation.
2. **Le site est-il critique ?** Client exigeant, premier passage de la semaine, accès limité (badge, clé), syndic avec contrôle qualité prévu.
3. **Y a-t-il déjà un backup nommé** pour ce site, ou faut-il chercher à froid ?

Sur un portefeuille multi-sites, cette cartographie doit exister *avant* le lundi. Sinon vous improvisez sous pression.

**Scénario bureaux :** une agente couvre trois open spaces sur le même secteur (7h–9h30). Si elle tombe, ce n'est pas un site orphelin — c'est trois. Vous devez voir la tournée entière, pas une ligne Excel isolée.

**Scénario syndic :** parties communes (hall, cages, locaux poubelles) le lundi matin. Le conseil syndical passe parfois en début de semaine. Un trou visible = mail au gestionnaire le soir même. Détecter tôt, c'est déjà gagner la demi-journée.

## Réaffecter un backup sans redistribuer toute la tournée au hasard

Réaffecter ≠ « le premier qui répond au téléphone ». Vous voulez le bon agent : proche, déjà formé au site, disponible sans casser trois autres contrats.

Ordre de priorité terrain :

1. **Backup nommé du site** — quelqu'un qui a déjà fait le tour au moins une fois.
2. **Agent du même secteur** — moins de trajet, connaissance des accès du quartier.
3. **Polyvalent disponible** — avec fiche site (codes, consignes, matériel) sous les yeux.

Ce que vous évitez : déplacer l'agent d'un autre client sensible pour « dépanner », puis créer un second trou. Un [logiciel de planning nettoyage](/logiciel-planning-nettoyage) sert exactement à ça : voir qui est libre, sur quel secteur, avec quelles compétences, sans relancer dix personnes.

**Bureaux multi-sites — exemple :**

- Site A (critique, badge + consignes sanitaires) → backup formé uniquement.
- Sites B et C (entretien standard, même immeuble) → agent du secteur, même si première fois, *si* la fiche site est à jour.

**Syndic parties communes — exemple :**

- Hall + cages d'escalier : priorité à quelqu'un qui connaît les locaux techniques et les jours de collecte.
- Si le backup ne connaît pas l'immeuble : lui envoyer la fiche (plan, codes, points sensibles) *avant* qu'il parte, pas en message vocal pendant qu'il conduit.

Préparez aussi le **plan B** : si aucun backup ne répond sous 20 minutes, qui appelle-t-on ensuite ? Responsable d'équipe ? Vous-même sur le site le plus critique ? Décidez-le à froid, pas à 7h15.

## Prévenir le client (proactif, court, factuel)

Beaucoup de gérants hésitent à appeler. Erreur. Un client prévenu reste un client. Un client qui découvre le trou seul part en réclamation — ou en appel d'offres.

Message type (mail / SMS professionnel / portail) :

> Bonjour [Nom],  
> Suite à une absence imprévue ce matin, l'intervention sur [site] sera assurée par [prénom / « un agent de l'équipe »] à [heure].  
> Les consignes habituelles sont reprises. Un compte-rendu / preuve de passage vous sera transmis.  
> Cordialement,

Trois règles :

- **Ne mentez pas** sur l'horaire. Mieux vaut « vers 8h30 » tenu que « 7h » raté.
- **Nommez un interlocuteur** côté client si c'est un syndic (gestionnaire, gardien).
- **Promettez uniquement ce que vous pouvez tracer** (voir étape suivante).

Sur les bureaux multi-sites, un seul message au contact principal suffit — pas un message par étage. Sur syndic, le gestionnaire apprécie d'être informé *avant* le premier locataire qui se plaint du hall.

Si le remplacement est impossible le matin même : proposez un rattrapage horodaté le jour même ou le lendemain, et confirmez-le par écrit. Le silence est pire que le décalage.

## Tracer le passage : la preuve qui ferme le sujet

Le remplacement n'est fini que quand vous avez la preuve. Sinon, lundi prochain, le client dira « personne n'est venu » — et vous n'aurez rien pour répondre.

Minimum utile :

- **Pointage** (arrivée / départ) sur le site.
- **Photo** des zones sensibles si le contrat ou le syndic le demande (hall, sanitaires, locaux poubelles).
- **Note courte** : « Passage backup, consignes OK, consommables à recharger » — visible pour vous, pas forcément pour le client.

Pour un syndic, ce tracé alimente le reporting mensuel. Pour des bureaux, il protège la relation quand le contact RH n'était pas sur place à 7h.

Sans outil, vous stockez ça dans des fils WhatsApp qui disparaissent. Avec un [logiciel pour entreprise de nettoyage](/logiciel-entreprise-nettoyage), le passage, le remplaçant et la preuve restent liés au site et au contrat — utiles aussi pour facturer le réalisé, pas le « prévu sur Excel ».

## Ce qu'il faut avoir préparé *avant* le prochain lundi

Le playbook du jour J ne tient que si la base est prête :

| À préparer | Pourquoi |
| --- | --- |
| Liste des sites critiques + backup nommé | Évite la recherche à froid à 6h40 |
| Fiches site à jour (accès, consignes, matériel) | Le backup travaille sans vous appeler 10 fois |
| Canal unique pour signaler une absence | Plus de message perdu dans 4 groupes |
| Modèle de message client | Envoyé en 2 minutes, ton pro |
| Règle d'escalade (20 min sans réponse → plan B) | Moins de panique, moins de sites orphelins |

Testez la procédure une fois hors urgence : simulez une absence sur un site non critique. Chronométrez. Vous verrez tout de suite où ça coince (fiche manquante, backup jamais formé, numéro obsolète).

## En résumé

1. **Détecter** vite : un canal, la tournée complète, la criticité.
2. **Réaffecter** avec méthode : backup nommé → même secteur → polyvalent + fiche.
3. **Prévenir** le client : court, factuel, horaire tenable.
4. **Tracer** le passage : pointage, photo si besoin, note — pour fermer le sujet.

Le lundi matin restera imprévisible. Votre réaction, non.
