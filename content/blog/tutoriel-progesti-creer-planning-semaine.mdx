# Tutoriel Progesti : créer un planning semaine multi-sites

Le lundi à 6h30, ce n’est pas l’Excel qui manque. C’est la vue claire : qui est où, sur quel site, avec quel statut. Sans ça, le remplacement part dans le mauvais hall et le syndic appelle avant le café.

Ce tutoriel montre le parcours réel dans Progesti : vue **Semaine**, filtres, bouton **Planifier**, détail d’un passage, vues **Clients** / **Agents**, puis **Dupliquer semaine**. Captures prises sur la démo produit (données fictives Pro Nettoyage Services).

Objectif terrain : une semaine lisible pour plusieurs sites, pas un tableau coloré pour la réunion.

## 1. Ouvrir la vue Semaine

Menu **Planning** → **Planning**. Onglet **Semaine**.

Vous voyez la grille horaire (lundi–vendredi), les blocs d’intervention, et en haut l’exploitation du jour : passages à pourvoir, passages en retard. À droite : **Planifier**, **Dupliquer semaine**, **Valider la semaine**.

![Vue planning semaine Progesti avec grille multi-passages et bandeau exploitation du jour](/tutoriels/tutoriel-progesti-creer-planning-semaine/01-planning-vue-semaine.png)

**Terrain :** commencez toujours par la bonne date. Une semaine décalée d’un jour et vous « validez » du vide pendant que le terrain court.

Les blocs orange avec bandeau vert = planifié / suivi. Rose avec **Annulé** = passage coupé. Le vert validé, vous le voyez aussi dans le détail passage plus bas.

## 2. Filtrer avant de toucher à quoi que ce soit

À gauche de la grille : **Statut intervention**, **Agent**, **Client**, cases **Interventions** / **Absences**.

Ouvrez le statut : Tous, À pourvoir, Planifié, Validé, Annulé. C’est là que vous isolez les trous avant d’empiler du nouveau.

![Filtres planning : statut intervention ouvert (Tous / À pourvoir / Planifié / Validé / Annulé)](/tutoriels/tutoriel-progesti-creer-planning-semaine/02-planning-navigation.png)

**Scénario bureaux multi-sites :** filtrez un client (le siège + l’open space Labège). Vous voyez les trous du client, pas le bruit de toute la flotte.

**Scénario syndic :** filtrez l’agent du secteur. Vous voyez sa charge avant d’ajouter un hall de plus le même créneau.

Bouton rouge **Annuler le filtrage** = retour vue complète. Utile après un sniper statut « À pourvoir ».

## 3. Planifier une mission sur la semaine

Cliquez **Planifier**. La fenêtre demande une **mission** (client + prestation déjà cadrés), puis deux chemins :

1. **Planifier le cycle** — pour le récurrent (horaires bureaux, parties communes).
2. **Intervention ponctuelle** — pour le one-shot (remise en état, dépannage, fin de chantier courte).

![Modale Planifier : choisir une mission puis cycle récurrent ou intervention ponctuelle](/tutoriels/tutoriel-progesti-creer-planning-semaine/04-planning-creer-ou-affecter.png)

Sans mission propre (client + site + prestation), vous planifiez dans le vide. C’est le même ordre que pour un [logiciel de planning nettoyage](/logiciel-planning-nettoyage) : d’abord le qui / où / quoi, ensuite le quand.

**Astuce :** ne créez pas dix ponctuels pour masquer un cycle mal paramétré. Le cycle tient la semaine ; le ponctuel gère l’exception.

## 4. Ouvrir un passage et corriger sans casser la mission

Depuis **Passages**, ou en cliquant un bloc, ouvrez le détail. Exemple démo : intervention 06:00 (1 h 30), client Agence Immobilière Occitanie Habitat, lieu « Agence vitrine », statut **Validée**.

À droite : **Remplacer l’agent** (liste + **Appliquer l’affectation**) et **Décaler l’horaire** (ce passage seulement, pas toute la mission).

![Fiche passage : infos client/lieu/prestation et remplacement d’agent avant départ terrain](/tutoriels/tutoriel-progesti-creer-planning-semaine/03-planning-passage-detail.png)

Bandeau jaune typique : passage validé bureau — remplacement ou décalage encore possible avant départ terrain. C’est exactement le moment où WhatsApp devient dangereux : trois messages, zéro trace, mauvais agent sur le badge.

## 5. Lire la semaine par Clients (multi-sites)

Repassez en **Planning**, onglet **Clients**.

Les passages sont groupés par client. Vous voyez d’un coup : Agence Immobilière Occitanie Habitat (Validée + Planifiée), Association Maison de Quartier, etc. Idéal pour un portefeuille multi-sites : un client, plusieurs créneaux, plusieurs jours, sans perdre le fil.

![Vue Clients du planning : passages groupés par client avec statut Validée / Planifiée](/tutoriels/tutoriel-progesti-creer-planning-semaine/05-planning-multi-sites.png)

**Checklist multi-sites utile :**

1. Le même client a-t-il deux sites le même créneau avec le même agent ?
2. Y a-t-il un trou le mardi matin sur un site « VIP » ?
3. Un passage **À pourvoir** traîne-t-il à moins de 48 h ?

## 6. Lire la charge par Agents

Onglet **Agents**. Liste alphabétique : qui a des passages sur la période, qui est vide (« Aucun passage sur cette période »).

Exemple : Garcia, Inès — 07:00–08:30 Boutique Maison & Déco, Validé. Benali / Bernard / Diallo vides sur la plage affichée.

![Vue Agents du planning : charge par agent et passages du jour](/tutoriels/tutoriel-progesti-creer-planning-semaine/06-planning-agents.png)

**Terrain :** avant d’accepter un nouveau contrat le lundi, regardez qui a encore de la marge. Un agent « plein » à 7h ne rattrape pas un site à 7h15 de l’autre côté du périphérique.

## 7. Dupliquer la semaine (ponctuels seulement)

Semaine propre ? Bouton **Dupliquer semaine →**. Confirmation : copie les **passages ponctuels planifiés** vers +7 jours. Les **missions récurrentes ne sont pas dupliquées** (elles vivent déjà sur leur cycle).

![Dialogue Dupliquer la semaine : copie des ponctuels vers +7 jours, récurrents exclus](/tutoriels/tutoriel-progesti-creer-planning-semaine/07-planning-autre.png)

Puis **Valider la semaine** quand la grille tient. Valider trop tôt = fausse sécurité. Valider trop tard = agents qui partent sur une version non figée.

## Pièges fréquents

- **Planifier sans mission** → trou dans la grille, rien à facturer derrière.
- **Tout en ponctuel** → la semaine suivante est à reconstruire à la main.
- **Filtrer oublié** → vous croyez la semaine vide alors qu’elle est juste filtrée sur un agent.
- **Remplacement WhatsApp hors fiche** → le planning dit A, le terrain fait B.
- **Dupliquer en croyant copier les récurrents** → non : seuls les ponctuels partent ; relisez la modale.
- **Ignorer « Passages en retard »** → le retard s’empile, la preuve client s’effrite.
